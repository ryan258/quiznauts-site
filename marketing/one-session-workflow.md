# One mission, one complete package

The practical unit is one reviewed quiz, not a week of unrelated posts. Keep this workflow beside the existing source quiz tools; it does not replace their approval gates or alter their question banks.

1. **Choose the question set.** In `../quiznauts`, select the actual mission and record its title, question IDs, scope, sources, and review state. The site sample lives separately in `data/quick_mission.json` and is not a video-ready source-project bank.
2. **Review the answers and explanations.** Confirm one defensible correct answer per question, plausible wrong options, fair wording, and source support. Use `docs/editorial-sources.md` for the website sample's lineage.
3. **Produce and screen the video.** Use the source project's documented workflow. Review real reading time, answer/reveal synchronization, audio if any, portrait/landscape crops, and the end-to-end render. A successful export is not final editorial acceptance.
4. **Make a truthful thumbnail.** Start with the social-kit SVG. Use a hook actually present in the video, a short readable title, and current atomic Mr. Big art. Keep key text away from crop/UI edges. Save the editable SVG beside the export.
5. **Assemble the upload draft.** Title, description, exact sources, thumbnail, audience setting selected by Ryan, and spoken-audio captions if needed. Do not infer a platform audience setting from the mascot's cuteness.
6. **Save one checkpoint.** Record the package folder and next action in `status.json`. If stopping here, use “review upload draft” as the next step; do not reconstruct everything next session.
7. **After explicit publication, record the URL.** Open the actual watch page and verify it is the intended video. Replace `[VIDEO URL]` with this exact URL before using launch copy.
8. **Make one supporting post.** Reuse a question/reveal pair. Preserve its question ID, correct option and explanation. Add image alt text and a readable caption; include the source where it helps the post stand alone.
9. **Make one supporting field note.** Expand a useful distinction or context, linking the exact video only after it exists. Avoid reposting the entire quiz answer set if the post works better around one question.
10. **Record the useful observation.** Save the live URLs and one actual thing learned from the posting/review experience. Choose the next mission deliberately; there is no automated next batch.

## Package receipt

Copy this small record for a real mission; none of the blanks is a publication claim.

```text
Mission title:
Source quiz path and question IDs:
Source/content review status:
Video master path and final review status:
Thumbnail SVG and PNG paths:
Upload title/description path:
Speech/caption status:
Exact live video URL (only after publication):
Supporting post IDs and asset paths:
Field note path:
Next single action:
```

Keep credentials and private account recovery material outside this project. Only public URLs belong in `data/properties.json`.
