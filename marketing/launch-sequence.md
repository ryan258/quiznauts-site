# A proposed 14-slot launch sequence

Use these as fourteen **work slots** across roughly two weeks if capacity allows. They are not a daily publishing promise, automation, deadline, or fixed schedule. Pause after any slot; the done marker and next action are enough to resume.

| Slot | One concrete action | Done when | Resume note |
| --- | --- | --- | --- |
| 1 | Confirm the intended channel and whether it already exists. | Owned channel URL/sign-in decision recorded privately; no duplicate created. | Next: save the verified public URL. |
| 2 | Choose the available display/handle combination. | Ryan sees and selects the actual available option. | Next: profile copy and avatar. |
| 3 | Apply the avatar, banner, bio and About draft. | Real upload/crop preview reviewed before saving. | Next: link back to the site only when it has a live address. |
| 4 | Read the local site and run the focused checks. | Source, keyboard/zoom, quiz and artwork concerns logged/resolved. | Next: choose the public domain/hosting when ready. |
| 5 | Select one launch mission in the source quiz project. | Questions, distractors, explanations and sources receive human review. | Next: produce the video package. |
| 6 | Produce and screen the complete mission video. | Actual pacing, audio if present, reading size and captions if spoken reviewed. | Next: thumbnail matched to the exact mission. |
| 7 | Make the final thumbnail and upload copy. | Thumbnail hook appears in video; title/description/source links accurate. | Next: final owner publication decision. |
| 8 | Publish only after Ryan chooses to do so. | Real video URL recorded, watch page checked, visibility confirmed. | Next: connect that exact URL to supporting posts. |
| 9 | Activate the site only after a separate owner publication decision. | Verified public domain and properties configured; hosted pages checked. | Next: confirm links from channel to site and back. |
| 10 | Introduce Quiznauts using draft P01 or P02. | Copy, image alt text, destination and actual account reviewed. | Next: a useful question post. |
| 11 | Share question/reveal pair P07 and P08. | Both cards, answer, source and mission destination agree. | Next: inspect the real crop and reading size. |
| 12 | Make one optional vertical adaptation. | Reviewed three-question clip exists; no missing context/captions. | Next: use the exact upload URL in a later post. |
| 13 | Reuse a field note with draft P05 or P11/P12. | Post offers value on its own and links to the correct page. | Next: note actual responses. |
| 14 | Record what was useful and choose the next single mission. | One next action saved; cadence remains a deliberate choice. | Next: start `one-session-workflow.md`. |
